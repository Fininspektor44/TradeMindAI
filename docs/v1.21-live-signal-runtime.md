# TradeMind Live Signal Runtime v1.21

## Назначение

Runtime связывает уже готовые аналитические блоки в непрерывный read-only контур:

1. собирает канонические volume-бары из общей папки MT5;
2. принимает только закрытые M5-бары по FX majors;
3. строит новые SMC, liquidity, Fibonacci, FVG, volume, momentum и ATR observations;
4. добавляет только новые BUY/SELL candidates;
5. оценивает их будущий результат в shadow-режиме;
6. объединяет исторические v1.16 outcomes и live outcomes в производный evidence journal;
7. запускает Signal Passport Factory;
8. передаёт допущенный паспорт в MT5 Signal-to-Risk Bridge;
9. получает ALLOW/BLOCK без отправки ордера.

## Изоляция данных

Исторические файлы v1.16 не переписываются. Runtime хранит новые данные отдельно:

```text
data/live_signal_runtime_v1/
  observations.csv
  candidates.jsonl
  outcomes.jsonl
  evidence_outcomes.jsonl
  events.jsonl
  state.json
  status.json
  factory/
  bridge/<login>/
  logs/
```

`evidence_outcomes.jsonl` является производным объединением исторических и live outcomes. Конфликт одного `signal_id` с разным содержимым блокирует запуск.

## Временная модель

Время исходного MT5-бара считается временем открытия по часам сервера. Runtime:

1. вычитает `ServerUTCOffsetHours`;
2. прибавляет `bar_seconds`;
3. использует полученное UTC-время закрытия как момент доступности сигнала.

Это предотвращает использование незакрытой свечи и исключает трёхчасовой сдвиг брокерского сервера.

Для текущего счёта RoboForex используется:

```text
ServerUTCOffsetHours = 3
```

## Защита от дублей

- watermark хранится отдельно для каждого символа;
- без нового закрытого бара аналитика не пересобирается;
- observation идентифицируется через `observation_id`;
- candidate идентифицируется через неизменяемый `signal_id`;
- повторная запись с изменённым содержимым запрещена;
- глобальный Windows mutex не допускает параллельных запусков.

## Запуск

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\run_v121_live_signal_runtime.ps1" -Login "37365712" -ServerUTCOffsetHours 3
```

## Установка watch-задачи

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\install_v121_live_signal_watch.ps1" -Login "37365712" -ServerUTCOffsetHours 3
```

Задача проверяет источник каждую минуту. Полный анализ запускается только при появлении нового закрытого M5-бара.

## Состояния

- `RUN_COMPLETE`: обнаружен новый закрытый бар, контур выполнен;
- `WAITING_NO_NEW_CLOSED_BARS`: новых закрытых баров нет;
- `WAITING_SOURCE_EMPTY`: нет пригодных закрытых FX M5-баров.

Дополнительно `status.json` содержит состояния Factory, Bridge и Risk Manager.

## Граница безопасности

- orders OFF;
- publication OFF;
- broker API не вызывается;
- советники и настройки MT5 не меняются;
- grid robots не используются как источник сигнала;
- `ALLOW` остаётся расчётным решением Risk Manager, а не командой брокеру.
