# Рабочий процесс AOExtremum через GitHub

## Правило версий

- `main` содержит только проверенные версии.
- Каждое изменение выполняется в отдельной ветке `feature/...` или `fix/...`.
- Исходник MQ5, SET-файлы и инструкция меняются одним комплектом.
- После компиляции и тестов открывается Pull Request с результатами.
- В `main` версия попадает только после успешной компиляции и контрольного прогона.

## Что прикладывать к Pull Request

- список изменений;
- результат компиляции MetaEditor;
- оба отчёта A/B, если менялась торговая логика;
- прибыль, equity drawdown, Profit Factor, Recovery Factor;
- найденные ошибки и ограничения;
- финальный SET-файл.

## Именование

- исходник: `AOExtremum_..._vX_XX_NAME.mq5`;
- тестовый SET: `AOExtremum_vX_XX_NAME_TEST.set`;
- контрольный SET: `AOExtremum_vX_XX_BASELINE.set`;
- ветка: `feature/vX.XX-short-name`;
- исправление бага: `fix/vX.XX-short-name`.
